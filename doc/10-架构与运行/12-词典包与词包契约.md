# 词典包与词包契约

> 三类随包数据资产的键集契约与守护测试。修改任何词包前先读本文；新增/修改文案必须有回归测试（AGENTS.md）。

## 三类数据资产

| 资产 | 位置 | 消费者 | 结构 |
|---|---|---|---|
| TUI locale bundle | `locales/*.json`（25 语言） | `I18nRegistry`，全 UI 通用 `t()` | `{ messages: { "pi.slash.<name>.description": … } }` |
| core-hacks 精确词典包 | `src/core-hacks-locales/*.json`（9 文件，en 为空基线） | `tCore`/`tSelector` 的 exact 替换 | `{ version, locale, exact: { 英文原文: 译文 } }` |
| think 预制 baseline | `src/think-locales/*.json`（12 语言 + en 源） | B 线三层查询第①层 | `{ tool: {…}, param: {…} }` |

三者的键集契约独立维护，不互相复制。

## core-hacks 词典包契约

1. **en.json 的 exact 必须为空**：英文原文即显示，加条目会让 en locale 把英文替换成自己。
2. **zh-CN 是键集基准**：其余 8 个维护语言必须覆盖全部 zh-CN 键，缺失即该语言残留英文。
3. **zh-TW 双层**：legacy 表（动态正则）先跑，pack 补静态键；pack 值用台湾术语（供應商、工作階段、串流…），大陆惯用词不得出现。
4. **枚举值整行匹配**：`fullscreen`、`all`、`auto`、`true` 等短泛词在 `EXACT_WHOLE_LINE_ONLY_KEYS` 白名单，禁止子串替换。
5. **描述句内的枚举 token 用本语言译法**：如 `'one-at-a-time'`、`'all'` 在译文里写 `'逐条发送'`、`'全部'`（es/fr 的 `'auto'` 同形保留）。
6. **上游措辞变更时旧 key 保留**：新增当前措辞 key，不删除旧措辞（legacy 语言包与旧版 Pi 兼容依赖），由分层测试守护。
7. **上游删除的功能同步删 key**：如 `/llama`（Pi 1.5.x 移除），并在测试断言不回流。

守护：`tests/core-hacks-locale-alignment.test.ts`（契约）、`scripts/verify-core-hacks-locales.mjs --check`（CI 可用）、`tests/settings-localization.test.ts`（分层措辞）。

## locale bundle 契约

1. `pi.slash.<name>.description` 覆盖当前 Pi 全部内置命令；en 基准与上游同步（`tests/slash-i18n.test.ts` 断言 stale baseline）。
2. bundle 同时登记 namespaced key 与 stripped key（`I18nRegistry` 注册时双向存储）。
3. 快捷键、占位符、语义在所有语言保持一致。

## think baseline 契约

1. 12 语言（zh-CN/zh-TW/ja/ko/ru/vi/es/pt-BR/de/fr/id/hi），`en.json` 是英文源。
2. pi 升级后用 `node scripts/export-think-baseline.mjs` 重导英文源，比对差异；新工具走运行时兜底，稳定后固化进 baseline（ADR 0003）。
3. 只含 `description` 散文，不含字段名/type/enum/值。

## 修改流程

1. 改 zh-CN pack（键集基准）。
2. 同步其余 7 语言（`verify-core-hacks-locales.mjs` 无 `--check` 模式可先看缺口）。
3. 跑 `npm test`（alignment 契约测试会拦缺失）。
4. 涉及 UI 行为时 `python3 scripts/tui-smoke.py` + 真实 TUI 目标语言切换。
