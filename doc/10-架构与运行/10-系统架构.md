# 系统架构：三条本地化线与运行入口

> 当前架构权威。pi-di18n 是 Pi 的全量本地化扩展，承接 `pi-i18n` 的 TUI i18n/core-hacks 路线，整合 `pi-compaction-i18n` 的摘要本地化，并新增 LLM-facing 的思考语言本地化。当前行为以 `../index.ts` 与 `../src/` 为准，本文解释结构与边界。

## 三条本地化线

| 线 | 受众 | 管道 | 数据 |
|---|---|---|---|
| A 线 TUI 本地化 | 人（用户看到的界面） | core-hacks 运行时 patch + runtime UI description 缓存 | `src/core-hacks-locales/*.json` + `~/.pi/agent/state/pi-di18n/ui.json` |
| B 线 思考语言本地化 | LLM（provider payload 的 tool/param description） | baseline → 缓存 → LLM 兜底 三层查询 | `src/think-locales/*.json` + `~/.pi/agent/state/pi-di18n/think.json` |
| C 线 摘要本地化 | 人（`/compact`、`/tree` 摘要） | 接管 `session_before_compact` / `session_before_tree` | `src/compaction/` 模板 |

三条线共享同一 locale 真相源：`/lang` 命令与 `I18nRegistry`。任何子模块不得另建环境变量检测或平行 locale 状态。

## 运行入口与事件流

`index.ts` 是唯一的扩展组合入口：

```text
session_start
  ├─ locale 落定（config/env → /lang 最终确认）
  ├─ header/footer 本地化（think 状态进 footer）
  ├─ A 线：prefetchUiDescriptionsOnSessionStart（异步预翻译命令描述 → ui.json）
  └─ B 线：prefetchOnSessionStart（异步预翻译 tool/param description → think.json）

before_provider_request
  └─ B 线：applyOnProviderRequest 替换 payload.tools 的 description
     （三层查询：baseline → 缓存 → 同步 LLM 兜底；失败回退英文，不阻塞）

/session_before_compact、/session_before_tree
  └─ C 线：本地化摘要生成（独立 routing session，失败返回 cancel）

/lang 命令
  ├─ 语言切换：I18nRegistry.setLocale + ctx.reload()（重走 session_start）
  └─ 子命令：think / debug / probe / hacks / setup / demo
```

`installCoreHacks()` 在首次使用时 patch Pi 内部渲染路径（slash 描述、selector、状态提示、settings 值等）；patch 是 best-effort，匹配失败安全降级为英文。

## locale 真相源与状态文件

| 位置 | 内容 | 写入者 |
|---|---|---|
| `~/.pi/agent/state/pi-di18n/config.json` | 用户 locale 选择 | `/lang` 命令 |
| `~/.pi/agent/state/pi-di18n/think.json` | B 线：`enabled` 全局默认 + 各 locale 翻译缓存 | 缓存写入；`enabled` 只应由用户手工/配置修改 |
| `~/.pi/agent/state/pi-di18n/ui.json` | A 线：runtime 命令描述翻译缓存 | 预翻译/兜底写入 |
| `~/.pi/agent/state/pi-di18n/compaction.json` | C 线：可选 model override | 用户手工 |

think 的 `enabled` 语义（ADR 0002 后记 + 2026-11-14 修复）：磁盘值是**全局默认**，会话内 `/lang think on|off` 只改本会话内存副本；缓存落盘时 `enabled` 字段固定写磁盘全局默认，任何会话的运行时开关都不得毒化磁盘。全局默认 off 时新会话启动为关，会话内可临时开启。

## 兼容基线策略

- 目标基线：`@earendil-works/pi-coding-agent` 1.5.x；早期基线（0.83.x、1.1.0）尽力保留。
- 每次 Pi 升级从实际包版本和 dist 产物重新探测锚点：`/lang debug`、`/lang probe` + `node scripts/verify-core-hacks-locales.mjs --check` + `python3 scripts/tui-smoke.py`。
- 词包 key 是内容契约：上游改措辞时新增当前措辞 key，旧措辞 key 保留（legacy 语言包仍覆盖），由 `tests/settings-localization.test.ts` 分层守护。
- 上游删除的功能（如 `/llama`）同步移除词包 key，并在测试中断言不回流。
