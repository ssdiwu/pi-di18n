# 术语表

| 术语 | 含义 |
|------|------|
| pi-di18n | 本项目：接手 `pi-i18n` 的 TUI i18n/core-hacks，整合 `pi-compaction-i18n` 摘要本地化，并新增 LLM 思考语言本地化（自适应用户 locale）。 |
| core-hacks | 运行时 patch pi 内部渲染路径的机制，用于在上游无原生 i18n API 时翻译 TUI 文案。 |
| slash 命令 | pi 中以 `/` 开头的内置命令，如 `/settings`、`/compact`、`/tree`。 |
| slashDescMode | core-hacks 对内置 slash 命令描述本地化的诊断状态：`primary`、`fallback` 或 `none`。 |
| primary | 直接 patch `BUILTIN_SLASH_COMMANDS` 的 description，命令描述从源头本地化。 |
| fallback | 未能修改 core 命令源，但通过 autocomplete 输出层尽量翻译用户看到的描述。 |
| probe | core-hacks 的运行时探针，记录 patch 点是否匹配、命中和产生翻译。 |
| bundle key | locale bundle 中的翻译 key，如 `pi.slash.compact.description`。 |
| compaction | pi 的上下文压缩摘要流程，对应 `/compact` 或自动压缩。 |
| tree summary | pi 切换会话树分支时生成的分支摘要。 |
| 思考语言本地化 | 让 pi 发给 LLM 的 prompt 自适应用户 locale（中文用户用中文思考，日文用户用日文）。覆盖 tool/param/skill description 翻译；pi 核心行为指令暂不翻译。 |
| 预制 baseline | 随 pi-di18n 发布的 tool/param/skill description 预制翻译表（区别于随包的 TUI bundle，也不同用户本地翻译缓存）。第一版覆盖 12 种语言，其余走运行时兜底。 |
| 预制翻译 | 统称随包发布的预制内容，包括 TUI bundle（core-hacks-locales）和预制 baseline（tool/param/skill）。 |
| 翻译缓存 | LLM 运行时翻译后落盘到 `~/.pi/agent/` 下的 JSON 缓存，下次直接复用，避免每轮重翻。 |
| 翻译源优先级 | 查某条 description 的翻译顺序：预制 bundle → 翻译缓存 → 标记 pending 交给 LLM 翻译。 |
| 预翻译 | `session_start` 时检测到缓存缺失的工具，主动启动 LLM 翻译写入缓存。覆盖冷启动和 `/lang` 切换两个场景（`/lang` 最后 `ctx.reload()` 会重走 `session_start`）。 |
| 翻译兜底 | `before_provider_request` 发现某条 description 缓存还没好就同步翻这一次，保证 LLM 一定读到目标语言。 |
| `/lang think` | 思考语言本地化的纯开关子命令，不持有语言（语言由 `/lang` 的 locale 决定）。默认关；`on`（=`auto`）LLM 跟随当前 TUI locale 思考，`off` 关闭（LLM 用英文 description），无参查状态。 |
