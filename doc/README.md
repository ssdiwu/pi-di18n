# doc 文档导航

> 本目录记录 pi-di18n 的当前架构、术语、决策、路线图与版本实施方案。**当前实现权威**：A 线 core-hacks 运行时 patch + runtime UI 本地化，B 线思考语言三层翻译，C 线摘要本地化；结构见 [10-架构与运行/10-系统架构.md](./10-架构与运行/10-系统架构.md)。

## 阅读顺序

接手 pi-di18n 或做架构/词包决策前，按以下顺序阅读：

1. [术语表.md](./术语表.md) — 项目语言与固定叫法（跨段引用，故留根；命名权威）
2. [10-架构与运行/10-系统架构.md](./10-架构与运行/10-系统架构.md) — 三条本地化线、运行入口与事件流、locale 真相源与状态文件、兼容基线策略
3. [10-架构与运行/11-三条线机制与数据流.md](./10-架构与运行/11-三条线机制与数据流.md) — A/B/C 各线内部机制、三层翻译源、缓存失效语义
4. [10-架构与运行/12-词典包与词包契约.md](./10-架构与运行/12-词典包与词包契约.md) — 三类词包资产的键集契约、修改流程与守护测试（词包改动必读）
5. [10-架构与运行/core-hacks-ui-boundary.md](./10-架构与运行/core-hacks-ui-boundary.md) — TUI patch 的 fail-soft 边界与高风险路径
6. [决策档案/README.md](./决策档案/README.md) — ADR 索引；运行时翻译路线、description 边界、baseline 策略、工具结果投影
7. [30-路线图/路线图.md](./30-路线图/路线图.md) — 项目演进路线（B 线切片已全部落地）
8. `../index.ts` 与 `../src/` — 当前行为事实；`src/README.md` 是代码组织入口

## 目录职责

| 目录 / 文件 | 职责 | 是否权威 |
|---|---|---|
| `术语表.md` | 当前概念、命名与固定叫法 | 是，命名权威 |
| `决策档案/` | 难逆转且有真实权衡的架构决策（刻碑）；入口为 `决策档案/README.md` | 是，决策权威 |
| `经验笔记.md` | 可变化的做法与避坑经验（活页，现象+做法+证据） | 否，活页参考 |
| `10-架构与运行/` | 当前运行架构：三线机制、词包契约、patch 边界 | 是，当前实现权威 |
| `30-路线图/` | 演进方向、切片状态与不做边界 | 是，路线图权威 |
| `40-版本实施方案/` | 现行版本级验证记录 | 受路线图与 ADR 约束 |
| `90-归档/` | 过期架构/版本文档（单版本适配历史等），仅追溯 | 否，仅查历史 |

> 惰性建段：`20-能力参考/`（外部能力事实库）暂无内容，等真有内容再建目录。

## 文档类型约定

- **架构决策（ADR）**：`决策档案/000N-中文标题.md`。只有同时满足「难逆转 + 无上下文会困惑 + 有真实权衡」才写；修订以「后记」追加，不改写原文；新增 / 更新 ADR 时同步 `决策档案/README.md` 索引。
- **术语**：当场写进 [术语表.md](./术语表.md)，不攒着批量补。
- **经验**：解决一个坑时，如果换一个无上下文的 agent 会重走一遍，就记入 [经验笔记.md](./经验笔记.md)；重复发生时在原条目追加证据。
- **路线图**：唯一权威在 `30-路线图/`，决策变化同步更新它 + 对应 ADR。
- **版本验证**：带日期，落 `40-版本实施方案/`；过期方案移 `90-归档/`，不从归档倒推实现。

## 维护规则

- pi 升级后新增 UI / slash 表面时：更新词包（按 12-词典包与词包契约 的修改流程）+ 新增当期验证记录；单版本适配细节不进 `10-架构与运行/`（那是当前架构权威，不是版本流水）。
- B 线实施进度见 [30-路线图/路线图.md](./30-路线图/路线图.md) 的切片状态。
