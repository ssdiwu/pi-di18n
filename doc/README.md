## 文档类型约定

- **架构决策（ADR）**：`10-架构与运行/adr/000N-xxx.md`。只有同时满足「难逆转 + 无上下文会困惑 + 有真实权衡」才写。
- **术语**：当场写进 [术语表.md](./术语表.md)，不攒着批量补。
- **路线图**：唯一权威在 `30-路线图/`，决策变化同步更新它 + 对应 ADR。
- **版本方案/验证**：带版本或日期，落 `40-版本实施方案/`。
- **归档**：过期方案移 `90-归档/`，不从归档倒推实现。

## 维护规则

- pi 升级后新增 UI / slash 表面时，同步更新 [10-架构与运行/](./10-架构与运行/) 的兼容性说明和测试。
- B 线（思考语言本地化）实施进度见 [30-路线图/路线图.md](./30-路线图/路线图.md) 的切片。
